# Articles

Articles, blog posts, and papers worth remembering — with what I actually took from them.

A book gets its own file. An article usually gets a row here, and a file only when it changes how I work.

## Template

```markdown
## [Title] — [Author] — [Date read]

Link:

### What it says
One or two sentences.

### What I take from it
The part that applies to my work.

### Do I agree?
Where I push back, and why.
```
