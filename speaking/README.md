# Speaking

Talks I give: preparation, the talk itself, and what I learned from delivering it.

## Why keep this?

A talk is a forcing function — you only find the holes in your understanding when you have to explain it to a room. Keeping the prep and the retro makes the next talk cheaper and better.

## Structure

One folder or file per talk. Conference talks, meetups, internal brown bags, workshops — all of it counts.

## Template

```markdown
## [Talk title]

**Event:** 
**Date:** 
**Audience:** (size, level, background)
**Duration:** 

### Abstract
The pitch I submitted.

### Key messages
The 2–3 things I want people to leave with.

### Preparation notes
Sources, demos, rehearsal notes, what I cut and why.

### Feedback
What people said, questions asked, what landed and what didn't.

### Retro
What I'd change next time.
```
